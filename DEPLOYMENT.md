# MOONKO website

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Vercel

Import `Zhange-Wei/moonko-website` into Vercel and select `development` as the production branch, or merge the reviewed code to `main` and deploy from there. The project has not been deployed automatically.

## Launch safety

Token supply, blockchain, contract address, launch date and community links are unconfirmed placeholders. Replace them only after official verification. The site must not imply a token is available to trade before confirmation.

## Accessibility and performance

The 3D scene is dynamically loaded, device pixel ratio is capped, mobile layout is responsive, and the site honors the system reduced-motion preference.
